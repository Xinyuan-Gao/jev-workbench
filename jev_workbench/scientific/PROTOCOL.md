# JEV 科学对比实验 v2：执行前协议

状态：阶段 A 的数据来源核查、验证集调优与接入检查已经完成；执行和最终分析正在完成独立复核。此文件在冻结前仍可修改，正式状态与成绩以 frozen.json 和完整 journal 为准。

## 研究问题与结论范围

在相同、预先固定的测试输入和标签定义下，JEV 网关、Gemini 网关与经过验证集选择的本地文本分类管线，谁能更可靠地返回正确类别？三类任务分别报告，不用一个跨任务总分决定排名。判断对象是明确记录的模型/服务和配置，不把网关 alias 当成已核实的官方版本。

优先保留中文意图分类、问题—片段相关性与首步 Agent 路由，并加入许可与标注明确的公开基准。具体数据源必须经过下载及标注核查才能加入冻结清单。自编边界样本单独标记，不能代替公开人工标注，也不能把另一模型的输出当成 gold。

分阶段实施：阶段 A 先冻结和完整执行 MASSIVE 中文意图与 T2 问题—片段这两个已有公开人工标签的任务。路由不取消，作为阶段 B 待真实两人独立标注、计算裁决前一致性、处理分歧并建立独立 train/dev/test 后，使用新的冻结记录执行。阶段 A 不能声称所有三个场景都已完成；阶段 B 的假设在其测试前确定，不把阶段 A 结果用于事后选择有利的路由比较。

## 数据验收

1. 每个正式场景至少 200 个独立测试单元。意图以去重后的原始话语/来源组为单元；相关性以 query 为抽样、划分和推断单元，多个 passage 不能把独立 query 数放大；路由以独立原始任务/来源组为单元。
2. 保存来源 URL、版本/commit、许可、下载文件 SHA256、原始记录 ID、原始标签及变换规则。标准数据使用官方划分，并审计重复；自建数据按来源/模板组做固定种子的分层划分，先划分后扩展。
3. 删除跨分区完全重复和预定词面近重规则命中的记录，不把词面筛查称为语义泄漏已全部排除。固定 NFKC、大小写与空白归一；字符 2–4 gram TF-IDF cosine ≥0.90、双方归一文本至少2字符时作保守剔除；更短记录仅做完全去重。保留 test 优先、validation 其次；问题—片段任务按 query 整组剔除，不能只删一个 passage。此审计向量器可以接触输入，但绝不复用于模型特征。RAG 可以共享公开检索语料，明确只验证新 query，不同时宣称验证了未见文档。保存所有剔除的原因、数量及类别分布。
4. 测试标签只供评分。模型输入仅从任务白名单构造，剥离 ID、标签、split、来源标注与标注理由；输入文本本身正常包含的业务词不能被删除。
5. 若路由数据没有可信人工标签，建立盲审清单与业务标签规则，未完成真实人工核验时只允许标记为辅助探索，不把它写成已完成的正式证据。
6. 公开基准可能进入模型预训练；记录污染不可排除这一边界。新写数据能减少公开记忆的影响，但没有真人标注就不能称为人工 gold。

## 模型与选择过程

本地基线：多数类、字符 TF-IDF + Logistic Regression、字符 TF-IDF + LinearSVC、XGBoost、LightGBM。树模型同时考察经过 train-only SVD 的文本表示；RAG 使用分开的 query/passage 表示与相似度、重叠等交互特征，不能只保留简单拼接的失效实现。

每个可训练基线至少 12 个预先指定配置，在 train 拟合、在 validation 选择。选择指标为验证集全样本 Macro-F1，平分时按预先固定的参数顺序选择，不声称计算了严格的模型复杂度。所有特征变换仅在 train 拟合。本轮不使用 test 做特征、参数、阈值或 prompt 选择。记录全部候选成绩与选择理由，不能只保留最佳值。比较对象是使用公开训练集的本地监督学习管线与零样本调用的预训练服务，输入与评分统一，但训练资料、算力与前置成本不相同。

远程模型获得相同的自然语言任务定义、标签语义和输入字段。只在 validation 比较预先列出的任务说明；调用协议保留原生差异并完整记录。固定温度/采样参数（如服务支持）、选项顺序、最大输出长度、超时和重试。服务不支持的参数明确记录，不伪装成已经固定。

最终主要比较预先固定的第 1 轮。远程至少 3 轮独立实际调用，本地随机模型至少 5 个固定训练 seed；确定性模型不复制同一输出冒充独立重复。追加重复用于稳定性分析，不能增加独立样本量。重复次数在正式测试前按可核实预算固定；若预算不能支持最低次数，协议标记为未通过，不能称为完整实验。

## 失败、执行与原始记录

冻结 manifest 中每个样本/模型/重复组合必须都有 terminal record。HTTP 超时、限流重试耗尽、过滤拒答、无法解析、非法标签分别计数；单条失败继续下一条。运行中断后恢复相同 manifest，只提交尚未结束的组合，已经取得的错误/拒答不因刷新而消失。

保存每次尝试的脱敏请求 JSON、HTTP 状态、原始响应文本/JSON、request ID、返回 model、usage、开始/结束 UTC、网络耗时、等待和重试原因。禁止记录 Authorization、API key、cookie 或其他凭据。仅对网络/明确暂时性 HTTP 错误做最多 2 次重试，不改写 test 来消掉拒答；错误标签、拒答、解析失败不自动重测挑结果。

合法类别与合法置信度分开检查。有效类别仍可用于分类指标，缺失/非法 confidence 不能抹掉已取得的类别。概率未归一、定义不同或缺失时，不强行补出分布或做跨模型校准排名。

延迟分别报告首尝试、含重试的业务完成时间、失败耗时；本地分开记录训练、特征拟合与单条预测。单条本地时间包含特征变换、predict，以及支持概率时的 predict_proba，不称纯模型推理时间。候选报告重复引用的 feature_fit_ms 不得按候选数重复相加。usage 能证明 token 数，不能证明费用；没有可核实单价或账单时费用记未知。

## 指标、区间与比较

主指标：全提交正确率、全提交 Macro-F1、有效输出率。失败在全提交分类指标中作为未答对/相应 gold 类漏报计入；另报有效输出正确率与 Macro-F1，明确其条件分母。

报告每类 precision/recall/support、混淆矩阵、错误与拒答清单、重复轮一致率/波动、延迟均值/中位数/p95。RAG 另报相关类 recall，避免“全丢弃”以总体一半正确掩盖漏检。

95% 区间与模型差值主要用成对、按独立单位重采样的 bootstrap（10,000 次、固定统计 seed）。MASSIVE 每类限额抽样采用按 gold 类分层的组 bootstrap，保持类别抽样配额，避免重采样缺席类别人为压低 Macro-F1；稀有类样本不足另列，条件经验区间不能证明其总体表现已经确定。同一 RAG query 的全部 passage 一起抽样，不按 passage 的 gold 分层拆散 query。固定 60 个候选类别计算 MASSIVE Macro-F1，无支持类别按0计并公开support，另外报告测试有支持的59类Macro-F1；所有模型使用同口径。McNemar exact 仅用于真正独立的一对一观测；RAG 的正确率差异检验按 query 成对置换。确认性比较为 JEV–Gemini 与 JEV–validation 选出的最佳本地基线，主假设指标为全提交正确率、按正式任务数做 Holm 多重比较校正；Macro-F1 和其他比较保留区间并标记探索性，不把未检验指标称为统计显著。

不预先保证显著差异。n=200 在最不利比例附近的单比例 95% 区间半宽约 7 个百分点；小差异可能仍无法区分。样本规模、独立组数量、最小有意义差异和预算会一起写入冻结清单，不因看到显著/不显著而随意停止或扩样。

测试前样本量敏感性核算保存在 audits/design_sensitivity.json，计算经过独立枚举复核。以 5 个百分点正确率差异为假设，558 个独立二元正确性对、20% 不一致率、四比较家族最保守首门槛 alpha=.0125 的检出概率约 52.6%；不一致率10%时约88.8%。这些是假设条件下的功效，不是模型实测，也不保证语音助手分层样本满足完全 IID。T2 主指标是共享 query 的片段正确率，组内相关和差异分布未知，不能凭200个问题宣称80%功效。正式结果以差值区间表达精度，未显著不意味着等效，不做观察 test 后追求显著的扩样。

阶段 A 确认性家族在本次冻结内为两个任务各两比较，共四项；路由后续作为独立阶段预先登记其分析范围，完整项目报告明确阶段差异，不能把跨阶段事后比较写成同一次确认性检验。
